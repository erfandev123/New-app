🎯 What This Application Does: 

This is a full-featured social media marketing platform that offers: 
📱 Social Media Services: 

     TikTok Services - Views, Likes, Followers
     YouTube Services - Subscribers, Likes, Comments, Views
     Instagram Services - Followers, Likes, Comments
     Facebook Services - Page Likes, Post Engagement
     Twitter/X Services - Followers, Likes, Retweets
     And many more platforms...
     

💎 Digital Products: 

     Premium Subscriptions - Netflix, YouTube Premium, Spotify
     VPN Services - NordVPN, ExpressVPN, Hotspot Shield
     Software Premium - Canva, CapCut, ChatGPT Premium
     Gaming Top-ups - Free Fire Diamonds, Mobile Legends
     

🔧 Key Features: 

     User Management - Registration, Login, Profiles
     Service Catalog - 1000+ services with pricing
     Order System - Place orders, track status
     Payment Integration - Add funds, wallet system
     Admin Panel - Manage services, pricing, users
     Mobile-Responsive - Works on all devices
     Real-time Updates - Live order tracking
     

🛠 Technology Stack: 

     Frontend: React + TypeScript + Vite
     Backend: Express.js + Node.js
     Database: JSON-based storage (with Drizzle ORM setup)
     UI: Tailwind CSS + shadcn/ui components
     Authentication: Firebase Auth (with demo mode)
     State Management: TanStack Query
     

🚀 How to Use: 

     Access the Application: Open http://localhost:5000 
     Demo Mode: The app starts with a demo user automatically
     Browse Services: View available social media services
     Place Orders: Select services and place orders
     Admin Panel: Access /admin-services with admin key dev
     

📊 Admin Features: 

     Service Management: Edit prices, descriptions, limits
     User Management: View and manage users
     Order Management: Track and manage orders
     Custom Pricing: Set custom rates for different users
